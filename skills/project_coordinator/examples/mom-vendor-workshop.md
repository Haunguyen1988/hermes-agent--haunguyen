# Example — Vendor Workshop MOM

## Use Case
Create a clean MOM after a vendor clarification workshop.

## Example Prompt
Write a MOM after an AIMS vendor workshop covering access model, reporting logic, and next actions.
Include decisions, open points, and action items.

## Example Output

# MOM — AIMS Vendor Clarification Workshop

## Purpose
Clarify access segregation logic, reporting impact, and key dependencies for the target operating model.

## Key Discussion Points
### Access Model
- Vendor explained that access restriction is primarily controlled through role and configuration logic.
- Internal team noted the need to confirm practical segregation in day-to-day operation.

### Reporting Logic
- Vendor indicated that reporting behavior may depend on existing filtering and configuration approach.
- Internal team requested clearer explanation of how shared data environments affect reporting outputs.

## Decisions / Agreements
- A second clarification round will be prepared focusing on high-priority governance and reporting questions.
- The internal team will prepare a structured question pack before the next session.

## Open Issues
- detailed access segregation behavior by user role
- reporting treatment in shared data scenarios
- support model if issue ownership overlaps between entities

## Action Items
- Hau: prepare vendor question pack
- Vendor: provide clarification on access and reporting logic
- Internal stakeholders: validate which open points are critical for decision-making

## Why This Is A Good Example
- useful post-meeting artifact
- turns workshop discussion into follow-up structure
- matches Hau's project coordination style
