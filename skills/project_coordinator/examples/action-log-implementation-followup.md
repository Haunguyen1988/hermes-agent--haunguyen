# Example — Implementation Action Log

## Use Case
Track open actions after implementation meetings or review sessions.

## Example Prompt
Create an action log for AIMS implementation follow-up with owner, due date, status, and dependency.

## Example Output

# Action Log — AIMS Implementation Follow-Up

| ID | Action Item | Owner | Due Date | Status | Dependency / Note |
|---|---|---|---|---|---|
| 1 | Confirm department access approval flow | Hau / Department Manager | [Date] | Open | Needed before user setup starts |
| 2 | Send structured clarification questions to vendor | Hau | [Date] | In Progress | Depends on internal review of top questions |
| 3 | Validate reporting logic with business users | Business Stakeholders | [Date] | Open | Requires vendor clarification first |
| 4 | Prepare draft SOP for access process | Hau | [Date] | Open | Can proceed in parallel |
| 5 | Review open risks and dependencies | Project Team | [Date] | Open | Include vendor response status |

## Why This Is A Good Example
- compact but useful tracker style
- easy to reuse after meetings or workshops
- reflects Hau's execution-focused follow-up practice
