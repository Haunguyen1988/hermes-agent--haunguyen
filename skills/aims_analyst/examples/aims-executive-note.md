# Example — Executive Note on AIMS Topic

## Use Case
Prepare a short executive note on an AIMS-related decision topic.

## Example Prompt
Write a short executive note for management on whether to proceed with further assessment of a shared AIMS operating model.
Use Recommendation / Rationale / Risk / Decision Needed.

## Example Output

# Executive Note — Shared AIMS Operating Model Assessment

## Recommendation
Proceed with a structured assessment phase before any commitment to a shared operating model.

## Rationale
A shared environment may offer process standardization, simplified support structure, and improved group-level visibility. However, the main decision should depend on whether access segregation, data governance, reporting control, and operational support remain robust in practice.

## Risk
The main risks are not purely technical. They include unclear data visibility, governance complexity, reporting ambiguity, and support difficulty if multiple business structures operate within the same environment without sufficient control logic.

## Decision Needed
Approve a focused clarification and fit-gap phase with vendor and internal stakeholders before deciding the target model.
