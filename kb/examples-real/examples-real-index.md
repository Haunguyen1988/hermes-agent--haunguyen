# Examples Real Index

This index explains the sanitized real-example documents stored under `kb/examples-real/`.

These files are derived from Hau's real professional materials and working patterns, but have been sanitized to remove or generalize sensitive details.

Their purpose is to help the agent learn from realistic examples without exposing private or restricted information.

---

## 1. `professional-profile-sanitized.md`
### Best Use
Use when the agent needs to understand:
- Hau's professional level
- likely stakeholder seniority
- scope of systems / operations work
- expected quality of deliverables

### Typical Task Fit
- executive summary tone calibration
- management-ready positioning
- deciding whether to write at specialist, lead, or manager level

## 2. `personal-operating-manual-sanitized.md`
### Best Use
Use when the agent needs to understand:
- Hau's preferred working style
- how outputs should be structured
- how audience adaptation should work
- what quality and safety rules to follow

### Typical Task Fit
- almost any task
- especially when shaping structure, tone, clarity, and next-step orientation

## 3. `vendor-communication-patterns-sanitized.md`

## 4. `analytics-reporting-playbook-sanitized.md`

## Recommended Priority Order

If the agent is unsure where to start, use this priority:
1. `personal-operating-manual-sanitized.md`
2. the most relevant domain-specific sanitized example
3. the relevant skill example under `skills/*/examples/`
4. the closest reusable template under `context/templates/`

## Usage Principle

These files should not be treated as static documents only.
They should be used as style and pattern references.

The strongest use case is:
- identify the output type
- identify the audience
- choose the closest sanitized real example
- combine it with the relevant skill and template
- generate the final output in Hau's style

## Final Note

As more real examples are added over time, this folder should become one of the most valuable parts of the workspace because it gives the agent realistic pattern memory, not just abstract rules.
