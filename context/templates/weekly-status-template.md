# Weekly Status Template

Use this template when Hau needs to prepare a weekly status report for project tracking, system governance, issue follow-up, implementation progress, reporting improvement, or management visibility.

The purpose of this template is to provide a short, structured update that makes progress, blockers, risks, and next steps easy to understand.

---

# [Weekly Status Title]

## 1. Reporting Period
State the week or reporting period covered.

## 2. Overall Status
Provide a concise status summary.
Examples:
- On Track
- At Risk
- Delayed
- Stabilizing
- Awaiting Decision

Add a short 2 to 4 line explanation if useful.

## 3. Key Progress This Week
List the main achievements or completed actions.
Focus on items that matter to stakeholders.

Examples:
- workshop completed with key departments
- vendor clarification received on core access model
- dashboard KPI scope aligned
- SOP draft completed for internal review
- issue workaround implemented successfully

## 4. Current Open Items / Blockers
List unresolved items affecting progress.
Examples:
- pending vendor response
- incomplete requirement confirmation
- access approval logic not finalized
- data quality issue under review
- dependency on ICT configuration

## 5. Risks / Concerns
Highlight the key risks that require attention.
Keep this short and practical.

## 6. Decisions Needed
State any decision or management support required.
Examples:
- confirm direction
- approve scope
- assign owner
- prioritize issue handling
- approve timeline adjustment

## 7. Actions For Next Week
State the key planned actions for the next period.
Focus on concrete next steps.

## 8. Action / Owner Snapshot
If needed, include a short table with:
- Action
- Owner
- Due Date
- Status / Note

---

## Management Summary Mode

When the audience is leadership, compress the report into:
- Overall Status
- Key Progress
- Top Risks / Blockers
- Decision Needed
- Next Week Focus

## Working-Level Mode

When the audience is the project team or operational stakeholders, add:
- more detail on blockers
- owner and due date visibility
- dependencies and follow-up status

## Writing Rules For This Template

When using this weekly status template:
- keep it concise
- focus on movement, not noise
- make blockers visible early
- make decision need explicit
- make next steps actionable

## Quality Standard

A good weekly status update should help Hau:
- align stakeholders quickly
- reduce repeated explanation in meetings
- show progress clearly
- surface blockers before they become bigger problems
- support governance and follow-up with minimal rework
